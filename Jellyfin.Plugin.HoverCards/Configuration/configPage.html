Hover Cards

Expanding hover preview for movie and series cards. Changes apply after reloading the web client (Ctrl+F5).

Includes rows from Home Screen Sections and KefinTweaks. Uncheck to use it on library and other pages too.

Behaviour

How long the pointer has to rest on a card before it expands. Default 450.
Width of the expanded card relative to the card. Default 1.5.
Small poster cards grow at least to this width. Default 380.
Instead of a floating preview, the hovered poster grows in place to a landscape card and pushes the following posters aside. Details are shown on the backdrop.
Shows e.g. "Play S2 E5" like streaming services do.

Content

Compatibility

Comma separated. Cards inside matching elements are ignored, e.g. .section0, [data-section-type="upcoming"].
